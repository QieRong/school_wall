# 校园表白墙

这是一个基于 **Spring Boot 3 + Vue 3** 开发的校园社交类项目，主要用于课程项目、个人学习和毕业设计参考。项目围绕校园生活场景，提供帖子发布、评论互动、私信、内容审核、AI 文案辅助、后台管理等功能。

项目定位比较明确：它不是商业化产品，也不是可以直接上线运营的成熟系统，更适合作为一个前后端分离项目的学习案例。

## 项目简介

校园表白墙是一个面向校园用户的社交平台，核心功能是发布和浏览校园动态。用户可以发布普通帖子或匿名帖子，也可以进行点赞、评论、收藏等互动。管理员可以在后台进行内容审核、用户管理、举报处理和基础数据查看。

项目中还加入了一些扩展功能，例如：

* AI 文案润色
* 实时私信
* 漂流瓶
* 热词墙
* 故事接龙
* 数据看板
* 敏感词管理
* 帖子审核与举报处理

这些功能主要用于丰富项目完整度，方便学习前后端分离项目的整体开发流程。

## 数据库说明

项目使用 MySQL 作为主要数据库，数据库脚本在根目录的 `biaobaiqiang.sql` 文件中。

数据库中包含用户、帖子、评论、收藏、关注、私信、举报、公告、AI 使用记录、漂流瓶、热词墙、故事接龙等相关表。

使用前需要先创建数据库并导入 SQL 文件。

```bash
mysql -u root -p -e "CREATE DATABASE biaobaiqiang CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p biaobaiqiang < biaobaiqiang.sql
```

## 本地运行

### 环境要求

* JDK 17+
* Maven 3.8+
* Node.js 18+
* MySQL 8.0+

### 启动后端

```bash
cd springboot
mvn spring-boot:run
```

默认后端地址：

```text
http://localhost:19090
```

后端数据库配置支持通过环境变量修改，也可以直接在 `application.yml` 中按自己的本地环境调整。

### 启动前端

```bash
cd vue-frontend
npm install
npm run dev
```

默认前端地址：

```text
http://localhost:3000
```

## 常用配置

后端支持以下常用环境变量：

| 变量名                    | 说明               |
| ---------------------- | ---------------- |
| `SERVER_PORT`          | 后端端口             |
| `DB_HOST`              | 数据库地址            |
| `DB_PORT`              | 数据库端口            |
| `DB_NAME`              | 数据库名称            |
| `DB_USERNAME`          | 数据库用户名           |
| `DB_PASSWORD`          | 数据库密码            |
| `JWT_SECRET`           | JWT 签名密钥         |
| `FILE_UPLOAD_PATH`     | 文件上传路径           |
| `FILE_BASE_URL`        | 文件访问基础地址         |
| `DEEPSEEK_API_KEY`     | DeepSeek API Key |
| `DEEPSEEK_DAILY_LIMIT` | 每个用户每日 AI 调用次数限制 |

如果不配置 `DEEPSEEK_API_KEY`，AI 相关功能将无法正常使用，但项目其他功能仍可运行。

## AI 功能说明

项目接入了 DeepSeek API，主要用于内容润色和文案生成。用户在发布帖子或故事内容时，可以使用 AI 辅助优化表达。

为了避免滥用，项目中设计了每日调用次数限制，并记录 AI 使用情况。使用 AI 辅助后的内容也会在前端展示相应标识，提醒用户该内容经过 AI 协助。
